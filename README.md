# Cyclistic Bike-Share Case Study: Maximizing Annual Memberships
*Google Data Analytics Professional Certificate Capstone Project*

## Project Overview
Cyclistic is a bike-share program in Chicago aiming to convert casual riders into profitable annual members. This project analyzes over 6 million trip records from August 2025 to July 2026 using Python (Pandas) for data cleaning and feature engineering, and Microsoft Excel for pivot calculations and visualization.

## Key Insights
* **Usage Purpose:** Annual members use Cyclistic bikes predominantly for weekday commuting (peaking Tuesday–Thursday), while casual riders surge on weekends for recreation.
* **Trip Duration:** Casual riders log significantly longer trips (~21.2 mins on average) compared to members (~12.4 mins).
* **Number of rides:** Members use Cyclistic service alot more than casual members.
* **Bike Preference:** Both segments favor electric bikes over classic models by roughly 2:1.

## Strategic Recommendations
1.	Target frequent casual riders with messaging focused on commuting value and membership savings.
2.	Promote memberships during weekends when casual rider activity is highest, as this provides the best opportunity to reach potential membership candidates.
3.	Develop digital marketing campaigns that highlight the convenience and cost savings of annual memberships for riders who use Cyclistic regularly.
